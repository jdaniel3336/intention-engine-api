# Intention Engine API

FastAPI backend for Intention Engine — turns a vague intention into a
clarified outcome, a plan, and a continuously-updated next action.

## Stack

- Python / FastAPI
- PostgreSQL + SQLAlchemy 2.0 + Alembic migrations
- JWT-based email/password auth
- Provider-agnostic LLM layer (Anthropic and OpenAI adapters behind one
  `LLMProvider` interface, selected via `LLM_PROVIDER`)

## Local development

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
# edit .env: set DATABASE_URL to a local Postgres instance, JWT_SECRET,
# LLM_PROVIDER + LLM_API_KEY

alembic upgrade head
uvicorn app.main:app --reload
```

API docs at `http://localhost:8000/docs` once running.

### Running tests

Tests use an in-memory SQLite database and a fake LLM provider — no
external services or API keys required:

```bash
source .venv/bin/activate
pytest
```

### Creating a new migration

```bash
alembic revision --autogenerate -m "describe the change"
```

Autogenerated migrations that touch a UUID column need
`import app.models.base` at the top (the custom `GUID` type isn't resolved
automatically) — the migration template already includes this import.

## Deployment (Railway)

`railway.json` and `Procfile` are included. Connect this repo to a Railway
project, attach a Postgres plugin (which sets `DATABASE_URL`
automatically), and set the remaining env vars from `.env.example`
(`JWT_SECRET`, `LLM_PROVIDER`, `LLM_API_KEY`, `CORS_ORIGINS` — set this to
your deployed frontend's URL). The release phase runs migrations
automatically before each deploy.

## Project layout

```
app/
  main.py             FastAPI app + router wiring
  api/                Routers: auth, intentions, actions
  models/             SQLAlchemy models
  schemas/            Pydantic request/response schemas
  services/ai/        LLMProvider interface + adapters, IntentionClarifier,
                       PlanGenerator, ProgressEvaluator (stub)
  db/                 Session setup + Alembic migrations
  core/                Settings, auth/security helpers
tests/
```

## Scope note

This implements the MVP vertical slice only (see the project's build
spec): signup/login, conversational clarification, plan generation,
dashboard, and marking actions complete. Expense tracking, decisions,
check-ins, and the AI re-evaluation engine have schema support only — no
endpoints or logic yet.
